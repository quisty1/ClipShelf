# ClipShelf

Нативный менеджер буфера обмена для Mac с Apple Silicon и macOS 14 или новее. Интерфейс на английском и русском; по умолчанию — English. Работает локально, без аккаунта, сервера, аналитики и сетевых запросов.

## Запуск

1. Распакуйте `ClipShelf-macOS.zip`, если используете архив приложения.
2. Перетащите `ClipShelf.app` в «Программы» и откройте двойным щелчком. Приложение появится в строке меню.
3. В macOS 14–15.3 отдельное разрешение на чтение буфера не требуется — нажмите «Начать». В macOS 15.4 и новее в приветственном окне нажмите «Разрешить чтение» и выберите **«Всегда разрешать»** в запросе macOS. Если выбран другой вариант, откройте настройки ClipShelf → «Настройки macOS» и найдите разрешение на чтение буфера для ClipShelf в разделе «Конфиденциальность и безопасность».
4. Для вставки по Enter нажмите «Настроить вставку» — приложение откроет нужный раздел Системных настроек. Включите ClipShelf. В macOS 27 с английским интерфейсом раздел называется **Privacy & Security → Device Control and Data Access**; в предыдущих версиях — **Конфиденциальность и безопасность → Универсальный доступ (Accessibility)**. Этот системный переключатель нужно включить самостоятельно. Пока разрешение не выдано, запись можно скопировать и вставить вручную через ⌘V.
5. Скопируйте новый текст, ссылку или изображение. Откройте историю сочетанием **⌘⇧V** или щелчком по значку ClipShelf.

Содержимое буфера до первого запуска не импортируется. После переноса приложения в «Программы» запускайте его оттуда, чтобы системные разрешения относились к постоянному расположению.

Сборка подписана локально (ad hoc), без Apple Developer ID и нотарификации. Она предназначена для локального использования на вашем Mac. После самостоятельной пересборки macOS может потребовать заново предоставить разрешение на вставку. Если переключатель ClipShelf включён, но приложение сообщает об отсутствии доступа, запись может относиться к прежней сборке: выделите ClipShelf в этом разделе, нажмите «−», затем «+» и добавьте текущую `.app` заново. Кнопка «Показать текущее приложение в Finder» в настройках ClipShelf помогает выбрать правильный файл.

## Язык и оформление

В настройках → **Appearance / Оформление** выберите **English / Русский** и тему **System / Light / Dark** (Системная / Светлая / Тёмная). Изменения применяются сразу ко всем окнам и меню и сохраняются между запусками. По умолчанию, включая обновление с прежней версии, используются English и системная тема. Системная тема следует оформлению macOS.

## Управление

| Действие | Клавиши |
|---|---|
| Открыть / скрыть историю | ⌘⇧V, изменяется в настройках |
| Выбрать запись | ↑ / ↓ |
| Вставить в предыдущее приложение | Enter или двойной щелчок |
| Только скопировать и закрыть окно | ⌘Enter |
| Перейти к поиску | ⌘F |
| Закрыть окно / отменить диалог | Escape |

Контекстное меню записи открывает действия вставки без форматирования, удаления пробелов по краям и смены регистра. Преобразования не меняют сохранённый оригинал. Здесь же можно добавить запись в избранное, в несколько коллекций или создать из текста шаблон. Существующие шаблоны редактируются через это же меню. Кнопка «Новый шаблон» создаёт заготовку с названием и текстом.

Коллекции создаются кнопкой `+` слева. Для переименования и удаления используйте контекстное меню коллекции. Удаление коллекции сохраняет её записи в истории. Кнопка с расходящимися стрелками увеличивает предпросмотр.

Щелчок правой кнопкой по значку в строке меню открывает паузу, настройки и команду завершения. Закрытие окна оставляет приложение работающим. Автозапуск выключен; его можно включить в настройках. macOS может запросить отдельное подтверждение объекта входа.

## Хранение и приватность

- По умолчанию сохраняются 1000 обычных записей за 30 дней. Избранное, шаблоны и записи коллекций сохраняются до ручного удаления.
- Данные: `~/Library/Application Support/ClipShelf/`. Метаданные и текст — локальная база Core Data / SQLite, изображения — папка `Images`. Настройки — стандартные настройки приложения `app.clipshelf.mac`.
- История не шифруется приложением отдельно. Доступ к папке ограничен текущим пользователем; защита диска зависит от настроек macOS.
- Кнопка с корзиной **Clear History… / Очистить историю…** рядом с заголовком истории и команда «Очистить обычную историю» в настройках удаляют обычные записи после подтверждения, сохраняя избранное, шаблоны и содержимое коллекций. Очистка охватывает всю историю независимо от поиска и фильтра типа; если обычных записей нет, кнопка отключена. «Удалить все записи» удаляет также избранное, шаблоны и записи коллекций после подтверждения. Пустые коллекции сохраняются. Это логическое удаление; гарантированное стирание следов из SQLite/WAL и резервных копий не выполняется.
- Исключения приложений настраиваются через выбор `.app`. Известные метки скрытого, временного и автоматически созданного содержимого пропускаются. Не все приложения помечают пароли: для таких приложений используйте исключения или паузу.
- Буфер проверяется раз в 500 мс. При смене активного приложения неподтверждённое содержимое пропускается, чтобы не записать данные из исключённого приложения под именем следующего. Поэтому очень быстрые копирования с немедленным переключением приложения могут не попасть в историю. Источник — приложение, активное в момент наблюдения; macOS не раскрывает надёжно автора каждой записи.
- Копирования при выключенном приложении, во время паузы или при запрещённом доступе не импортируются позднее.
- Изображения: PNG/TIFF до 20 МБ; TIFF преобразуется в PNG. Текст, RTF и HTML — до 5 МБ на формат. Файлы и папки не сохраняются. На предпросмотре длинного текста показывается фрагмент; полное содержимое доступно в увеличенном окне.
- Если предыдущее приложение закрылось, фокус изменился или разрешение отозвано, ClipShelf оставляет выбранное в буфере и показывает подсказку вместо отправки вставки в другое приложение.

## Сборка из исходников

Нужны Command Line Tools со Swift 6.2 или новее. Сторонних зависимостей нет.

```sh
cd ClipShelf
bash scripts/build-app.sh
open dist/ClipShelf.app
```

Чтобы указать каталог результата:

```sh
bash scripts/build-app.sh /полный/путь/к/каталогу
```

Скрипт собирает Release для arm64, включает EN/RU-ресурсы локализации, создаёт иконку и Info.plist, подписывает `.app` локально и проверяет подпись. Полный Xcode не нужен.

Модели используют Core Data вместо SwiftData: в установленных Command Line Tools отсутствует плагин `SwiftDataMacros`. Формат хранения локальный, синхронизации с iCloud нет.

## Проверки

```sh
swift run ClipShelfChecks
```

Команда запускает автоматические поведенческие проверки (включая EN/RU-ресурсы, сохранение языка и темы, очистку с сохранением защищённых записей и изображений после перезапуска и отказ сохранения при очистке): поиск и дубликаты, ограничения истории на 1000 элементах, сохранение защищённых записей, коллекции, редактирование шаблонов, восстановление базы, уборка файлов изображений, отказ первого сохранения, исключения и смена источника, конфиденциальные метки, собственные записи, HTML-only, RTF/HTML и изображения. Тесты работают во временных каталогах и с отдельными `NSPasteboard`; системный буфер пользователя не читают и не изменяют.

Используется исполняемый тестовый модуль с проверками и ненулевым кодом выхода при ошибке. В установленных Command Line Tools фреймворк Swift Testing неполон (`_Testing_Foundation` не содержит модуль), поэтому тесты запускаются без XCTest/Swift Testing и полного Xcode.

Дополнительная проверка нативных окон (нужна активная сессия macOS):

```sh
bash scripts/check-interface.sh
```

Она компилирует реальные типы приложения без точки входа и проверяет перевод заголовков нескольких открытых предпросмотров, переключение AppKit appearance и меню. Использует временную библиотеку и отдельные настройки; монитор, автозапуск и глобальная горячая клавиша не запускаются.

Режим проверки интерфейса создаёт отдельную библиотеку с примерами, не включает запись общего буфера, горячую клавишу и автозапуск:

```sh
open -n dist/ClipShelf.app --args --verify-ui
```

Дополнительные аргументы: `--light`, `--dark`, `--system` для темы; `--english`, `--russian` для языка; `--long` для длинного текста; `--empty` для отсутствия демонстрационных данных в новой библиотеке; `--protected-only` для очистки обычных демонстрационных записей; `--onboarding` для приветственного окна. Без переопределения язык и тема берутся из сохранённых тестовых настроек. `--reset-preferences` сбрасывает только тестовые настройки, обычные настройки приложения не затрагиваются. Для отдельной библиотеки можно передать переменную окружения `CLIPSHELF_VERIFY_DIR` при прямом запуске `dist/ClipShelf.app/Contents/MacOS/ClipShelf --verify-ui`. Обычный запуск не содержит демонстрационных записей.

Системные проверки чтения из Safari/TextEdit и автоматической вставки после выдачи/отзыва разрешений требуют участия пользователя в системных настройках. Они не подменяются успешными тестами отдельных сервисов. Результаты выполненных проверок — в прилагаемом отчёте.
